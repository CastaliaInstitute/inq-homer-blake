## Source lock

The Iliad XML drafting source is byte-identified in
`text/source-lock.md`. The Odyssey `grc1` record is catalog-locked to the
Perseus citation service and its 1919 Murray edition; a byte-level XML
snapshot remains a pre-approval task because the current canonical-greekLit
repository exposes a different Odyssey Greek edition identifier.
