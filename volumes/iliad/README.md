# *Iliad* volume plan

The volume preserves all twenty-four books. For each book, record its working
translation status, key passages, recurring figures, proposed plate locations,
and review-gate sign-offs. The image sequence should balance war, ritual,
grief, divine intervention, and the human costs of Achilles' anger.
