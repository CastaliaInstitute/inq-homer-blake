## Source lock

The Iliad and Odyssey XML drafting sources are byte-identified in
`text/source-lock.md`. Both are locked to the same pinned
`PerseusDL/canonical-greekLit` commit; the Odyssey record uses canonical
identifier `grc2`, which the repository metadata identifies as Murray's 1919
Greek edition.
