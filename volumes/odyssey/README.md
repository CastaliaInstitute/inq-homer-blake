# *Odyssey* volume plan

The volume preserves all twenty-four books. For each book, record its working
translation status, key passages, recurring figures, proposed plate locations,
and review-gate sign-offs. The image sequence should balance wandering,
disguise, recognition, hospitality, danger, and the restoration of a household.
